# Alarm response sheet: PAH-201

## Alarm

PAH-201, V-201 pressure high, set at 2.3 barg on PT-201 (tag PI201_V201_PRESS). Relief valve PSV-201 is set at 3.0 barg.

## Likely causes

- Loss of condenser duty on E-301: warm cooling-water supply, or TV-301 sticking.
- Loss of reflux: P-101 trips and P-101B does not start.
- Non-condensable gas building up in V-201.

## Operator actions

1. Confirm the reading against a second indication if one is available.
2. Follow SOP-E301-01 to check condenser cooling.
3. Check that a reflux pump is running and reflux flow is between 18 and 22 m3/h.
4. Tell the shift supervisor. Treat a rising trend as urgent; the time to PSV-201 set pressure depends on the cause.

## Consequence if ignored

Pressure can reach the PSV-201 set point and relieve to flare.
