# MR-2025-044: TV-301 stiction

## Finding

A valve signature test on cooling-water valve TV-301 showed stiction of about 4%. The valve moved in steps instead of smoothly, which made TIC-301 hunt.

## Work done

The packing was adjusted and the positioner recalibrated. After the work, stiction was below 1%.

## Recommendations

1. Repeat the valve signature test in six months.
2. Trend the difference between TIC-301 output and TV-301 position; more than 5% suggests sticking again.
3. Note that a healthy valve cannot make up for warm cooling-water supply: when TV-301 is already wide open, E-301 has no spare cooling.
